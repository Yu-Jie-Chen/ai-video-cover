# 可直接复制的通用 AI 指令

适合在支持读图的 AI 助手中使用。替换输入区后提交；没有图片的项目写“无”。如果使用纯文生图工具，先让助手据此输出具体生图提示词，再把那份具体提示词连同适用参考图交给生图工具。

```text
你是一名视频封面策划与视觉设计师。请根据我提供的内容制作一个吸引人、且不偏离视频观点的封面方案。

【我的输入】
口播稿或视频内容：{{粘贴全文，或写清主题与观点}}
目标受众：{{可选，不填时从内容推断}}
人物照片：{{附图编号；没有则写无}}
风格参考：{{附图编号；没有则写无}}
沿用的系列样式：{{可选；写明要延续的配色、字体和版式}}
画面比例/精确尺寸：{{可选；本次要求优先，其次参考图或已有系列，否则默认3:4}}
指定图中文字：{{可选；填写时按此原文，不自动改写}}
必须保留的品牌/文字/人物特征：{{可选}}
输出模式：{{生成封面 / 只写提示词}}
其他要求：{{可选}}

【工作要求】
1. 从内容里找到一个真实的矛盾、疑问或利益点，给出一个推荐发布标题。正文必须能回应标题，不能夸大结果或捏造数字、身份。
2. 将图中文字收敛为一至两行主标题，以及必要时的一句短副标题，保留理解主题需要的名词。先确定一份逐行定稿；提示词、成图校对和交付记录使用同一份文字。已向我展示的文字若再调整，简短说明变化；我指定保留的原文不要改。
3. 区分人物图与风格图。以我本次指定的身份照片为准，换了人像素材时使用新照片，保留相貌、自然表情和要求保留的特征；旧封面只借鉴指定的配色、字体气质和构图，不混入旧人物、旧文案和旧主题。
4. 没有人物照片时，以内容相关的物件或场景设计封面。只有在我明确要求保留某个人、却没有那个人的照片时，才补问照片。
5. 已有系列时延续配色和层级；我本次指定的比例或风格优先。背景和道具服务本期主题。按画布重新布局，文字不遮脸、边缘留白、缩略显示仍可读，不能把3:4拉伸成9:16。
6. 写一份具体生图提示词，包含用途与目标比例、实际参考图角色、主体与保留特征、主题背景、构图、色彩、逐字定稿及分行、字体与强调词。只保留本次需要的一套方案，移除变量、重复限制和不相关旧主题。
7. 如果我选择“只写提示词”，到此结束。如果选择“生成封面”且你具备生图能力，直接制作一张。对照定稿检查文案，比较本轮人像，检查裁切和主题；读取实际宽×高核对比例和精确尺寸，不能把目标值当成实测值。未达标时针对性修正，连续两次仍未解决就说明问题；无生图能力则明确说明，保留完整提示词。

【交付】
推荐发布标题；封面主标题与可选副标题；完整生图提示词；实际生成的图片（仅在已生成时）。
生成后的文件记录另含实际尺寸、比例与生成方式；未测量时标为未核验。不要把设计建议说成已有点击率效果，也不要在只写提示词时声称图片已经检查通过。
如果我明确限定只要其中某项，以该范围为准，例如只要一段生图提示词时不另列标题或设计说明。
```
