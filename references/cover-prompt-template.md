# 通用生图提示词模板

这是给图片生成工具的完整构图模板。实际生图前填实变量并删除不适用行；要求通用模板时保留变量。图片编号须与实际输入一致。不要把候选标题或说明文字一并印到画面里。

```text
任务：制作一张完成可用的静态视频封面。
视频主题与核心观点：{{主题及正文实际表达的观点}}
目标受众：{{受众}}
画布：{{宽高比；只有用户指定或工具实际支持时填写精确像素}}

参考素材及用途：
{{逐张列出图片编号和作用：人物身份来源、仅风格参考、必须保留的成品元素}}
{{有人物时：以指定人物照片为唯一身份来源，保留其真实五官、脸型、发型、眼镜、肤质与要求保留的服装。风格参考不得用于混合人物。}}
{{无人物时：以指定主题物件或场景为主角，不添加虚构讲述者。}}

整体风格：
{{从参考图或用户要求提炼的字体气质、颜色、背景、摄影/插画质感}}
参考图只借鉴指定的视觉特征，旧标题、品牌、职业身份和旧主题不沿用。

构图：
{{主角在画面中的位置、大小与视线；按横版/竖版分别安排}}
{{标题区域、副标题区域与留白；只保留一个主角和清晰文字层级}}
人物面部/主体关键区域清楚可见，文字不得遮挡。
重要文字和主体与四边保留适当安全距离，默认约5%；如有实际平台裁切框，按裁切框调整。
缩成手机缩略图时，主标题仍清晰可读。

背景与道具：
{{与稿件直接相关的环境和一至两个辅助线索}}
背景保持简洁与适度虚化，不让小物件和零碎文字抢走主标题注意力。

图中文字——以下是画面中唯一要印出的文字，逐字准确：
主标题第1行：“{{准确原文}}”
{{需要第2行时：主标题第2行：“准确原文”}}
{{需要副标题时：副标题：“准确原文”}}

排版：
{{各行字号关系、字体形态、描边/阴影的适用程度}}
{{具体强调词及其颜色，不依赖模糊的“把重点突出”}}
文字完整，不缺字，不重复，不出现乱码；整体间距整齐。

光线与色彩：
{{主色、辅助色、光线方向与气氛；人物肤色自然}}
{{有身份参考时：不要擅自瘦脸、更换年龄、过度磨皮或改变眼镜形状。}}

内容边界：
标题与视觉仅表达上述视频实际内容，不增加结果保证、统计数字或未经提供的身份背书。
没有额外口号、水印、品牌文字或多图拼版。输出单张封面成品。
```

修改成图时另列“保留项”和“本次修改项”，减少每次重做导致的人像与布局漂移。
