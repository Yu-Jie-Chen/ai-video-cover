# 通用生图提示词模板

这是给图片生成工具的构图模板。实际生图前填实变量、选定一种方案并删除不适用行；要求通用模板时保留变量。图中文字直接来自定稿，不在填模板时重新写一遍标题。图片编号须与实际输入一致，发布标题和候选标题不混入上图文字。

```text
任务：制作一张完成可用的静态视频封面。
视频主题与核心观点：{{主题及正文实际表达的观点}}
目标受众：{{受众}}
目标画布：{{本次确定的宽高比；要求精确像素时另列宽×高}}

参考素材及用途：
{{逐张列出实际输入的图片编号和作用：本轮人物身份来源、仅风格参考、必须保留的成品元素}}
{{有人物时：以指定的本轮人物照片为唯一身份来源，保留其真实五官、脸型、发型、眼镜、肤质、自然表情与要求保留的服装。旧封面仅参考风格，不用于混脸。}}
{{无人物时：以指定主题物件或场景为主角，不添加虚构讲述者。}}

整体风格：
{{本次要求或沿用的系列风格：字体气质、颜色、摄影/插画质感}}
参考图只借鉴指定的视觉特征，旧标题、品牌、职业身份和旧主题不沿用。

构图：
{{主角位置、大小与视线；根据本次比例安排，不拉伸上一张封面}}
{{标题区域、副标题区域与留白；只保留一个主角和清晰文字层级}}
人物面部/主体关键区域清楚可见，文字不得遮挡。
重要文字和主体与四边保留适当安全距离，默认约5%；如有实际平台裁切框，按裁切框调整。
缩成手机缩略图时，主标题仍清晰可读。

背景与道具：
{{与稿件直接相关的环境和一至两个辅助线索}}
背景保持简洁与适度虚化，不让小物件和零碎文字抢走主标题注意力。

定稿图中文字——以下是画面中唯一要印出的文字，逐字、逐行准确：
主标题第1行：“{{准确原文}}”
{{需要第2行时：主标题第2行：“准确原文”}}
{{需要副标题时：副标题：“准确原文”}}

排版：
{{各行字号关系、字体形态、描边/阴影的适用程度}}
{{具体强调词及其颜色，不依赖模糊的“把重点突出”}}
文字完整，不缺字，不重复，不出现乱码；整体间距整齐。

光线与色彩：
{{主色、辅助色、光线方向与气氛；人物肤色自然}}
{{有身份参考时：不瘦脸、不更换年龄、不重塑五官或擅改表情；调整曝光时保留真实皮肤纹理。}}

内容边界：
标题与视觉仅表达上述视频实际内容，不增加结果保证、统计数字或未经提供的身份背书。
没有额外口号、水印、品牌文字或多图拼版。输出单张封面成品。
```

调用前去掉重复限制和不相关旧主题，不把完整稿件和多套方案塞入同一份提示词。修改成图时另列“保留项”和“本次修改项”，保留已经合格的文案、人物和布局。

成图后的记录另存：实际使用的定稿文案、完整提示词、生成方式、实测宽×高和比例。先读文件尺寸，再报告是否达到目标；这些记录不要求印在图上。只输出提示词时，不虚构成图或实测结果。
